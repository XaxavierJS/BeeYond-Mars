# Migration review — historical v12 context

This document preserves the purpose and findings of the earlier migration review in English. Its old verification claims are not evidence that the current v13 checkout passed those checks. The authoritative current overview is README.md; sources are in SOURCES.md; public checks are in hackathon/VERIFICACION-PAGES.md.

## Earlier implementation findings

The migration separated mission rules from presentation and retained the biological payload, equipment, route comparison, design reviews, incidents, reporting and greenhouse concept. Story encounters, a notebook, launcher packages, timing controls, audio and local role sharing were added around that mission model.

Earlier corrections addressed inconsistent chamber specifications, funding, launcher feasibility, communications requirements, data conservation, time-proportional damage and accounting for emergency battery consumption. The prior reference project inventory is retained in gamemaker-inventory.json. Inventory inspection did not constitute native GameMaker compilation or per-frame artistic review.

## Differences that must not be carried forward as current facts

The historical v12 review described three routes and an arrival-generation factor based on the NASA irradiance ratio. The active v13 data contains two routes and the independent 0.85 generation simplification. Read data.js rather than copying historical balance values. The current route query provenance is still unverified in the delivered source register.

The original review listed broader engine tests and a complete desktop sequence. Those reports belong to that implementation: the current full suite fails because its legacy engine test imports deleted modules. Four current story tests pass. Published mission checks use prepared checkpoints and are documented separately.

## Design and science

The notebook and dialogue give resource decisions a personal context. General design inspirations included progressive collection, short consequential conversations and retry without humiliation. Such inspiration is not permission to copy another game's characters, music, maps or interface. The educational effects and emotional response have not been measured with an external cohort.

Terrestrial diapause research, honeybees in orbit and agency reference material do not prove interplanetary bumblebee survival. Mission prices, risk and outcomes are team-defined. Preserve this distinction when extending the product.
